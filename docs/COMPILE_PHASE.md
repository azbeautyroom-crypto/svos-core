## Purpose

Technically connect SVOS Core inputs to a generated SessionVue OS.

## Source

`inputs/sessionvue/`

## Compiler

`scripts/compile_sessionvue.py`

## Output

`generated/sessionvue-os/`

## First generated Business System

## Release gate
