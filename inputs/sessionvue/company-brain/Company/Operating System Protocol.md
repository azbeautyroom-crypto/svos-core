## Core Principles

1. Every recurring business process is a System.
2. Every System has one owner.
3. Every asset has one source of truth.
4. Information is never duplicated.
5. Systems reference information rather than copying it.
6. Decisions are documented.
7. Every task belongs to a System.
8. Every System has a lifecycle.
9. Nothing important exists only in someone's head.
10. Planning and implementation are separate. Planning lives inside the operating system. Implementation lives inside external execution tools.

## Before Any Work

- Which System owns this?
- Which department supports it?
- Is this planning or implementation?
- Does this already exist?
- Is there already a source of truth?

If the answer already exists somewhere else, reference it. Do not recreate it.
