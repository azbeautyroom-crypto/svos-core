# SVOS Release Process

Version: 1.0.0
Status: LOCKED
Owner: Founder

```text
Define
→ Build
→ Self-Review
→ Validate
→ Correct
→ Revalidate
→ Founder Review
→ Commit
→ Push
→ Tag
→ Release Notes
→ Install
→ Verify
→ Close
```

Every package must be scoped, reviewed, validated, approved when required, committed with explicit paths, pushed, and verified before closure.
